# Jack Admin Panel – Angular Frontend

A modern, scalable admin dashboard built using Angular.  
This project is designed for managing users, roles, and application data with a clean UI and production-ready architecture.

---

## 🚀 Features

- User management (list, pagination, status)
- Loading states & empty state handling
- Responsive admin layout
- Modular & scalable Angular structure
- API integration ready
- Environment-based configuration
- GitHub-ready project structure

---

## 🛠️ Tech Stack

- Angular (latest stable)
- TypeScript
- RxJS
- SCSS
- REST API integration
- Git & GitHub
